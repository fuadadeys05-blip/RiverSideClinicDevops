# RiverSideClinicDevops
Riverside Clinic DevOps.
This repository showcases how Riverside Community Clinic can move from a risky web-content process to a controlled delivery process using Github, pull requests, and automated
checks. 
The project utilizes fictional Clinic content such as opening hours and services. Github Actions automatically verifies the content 
whenever changes are pushed or proposed through a pull request. 
The repository also demonstrates DevOps Lifecycle planning ,CALMS assessment, user stories, CI pipelines design, failure troublshooting
, DORA metrics, and responsible use of an AI assistant.
